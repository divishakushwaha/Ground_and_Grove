# Grounds and Grooves

Cafe website: HTML/CSS/vanilla JS frontend + a tiny Node/Express + SQLite backend.
The backend only stores **orders**, **table reservations** and **feedback**.

## Run it
```bash
cd backend
npm install
npm start
```
Then double-click `frontend/index.html` (open with Microsoft Edge), or visit http://localhost:3000.

See saved data: `npm run view` (inside `backend/`), or open http://localhost:3000/api/orders in Edge.
Database file: `database/grounds_and_grooves.db`
